Overview

TradingAgents is a TypeScript financial research CLI with an interactive React/Ink terminal and a headless one-question mode. A configured language model decides what to investigate. The application runs the requested tools, computes quantitative metrics locally, and gives the model bounded results to synthesize into an answer. Its scope is research and reporting.

The two pasted runs expose the most important architectural distinction. Apple’s company data, pricing, and news came from Tauric. For SMH, the pricing calls reached Yahoo after Tauric reported a coverage gap. Both runs could calculate return and risk statistics because the compute layer consumes the same form of historical series.

README · CLI usage · Package manifest

Key features

Interactive and headless
Ask follow-up questions in the terminal or use tradingagents -p "Analyze AAPL" --json to consume turn events as JSON Lines. Auto mode proceeds with research. Plan mode presents a plan for review.
Specialists and skills
Equity, macro, quant, and risk specialists can run with their own context and tool access. Markdown skills provide research procedures. Users can add agents and skills through the catalog.
Model and data configuration
Model providers include Tauric AI, several hosted vendors, OpenAI-compatible endpoints, and ChatGPT sign-in. The model route and data provider routes are configured separately.
Financial data and compute
Tools cover quotes, history, company profiles, analyst estimates, filings, statements, ownership, news, and macro series where supported. Local tools compute returns, beta, correlation, indicators, portfolio statistics, and valuation scenarios.
Evidence and reporting
Structured tool results carry evidence IDs and provenance. Compute tools can reference prior results directly. Answers show numbered sources, and the terminal supports PDF answer export and Markdown transcript export.
Session continuity
Append-only session logs support resuming conversations. Optional Tauric sync applies eligibility rules to evidence payloads. The engine manages cancellation, turn budgets, and context compaction.

Software architecture

Key code paths

StageRuntime behavior
Startupmain.tsx resolves configuration and opens a session. createEngine wires the model, provider capabilities, tools, agents, and limits. Yahoo and Polymarket are available without a Tauric key in the default setup.
OrchestrationEngine.ask manages the turn and evidence scope. runAgent alternates streamed model steps with tool execution. Adjacent parallel-safe calls may run concurrently. Delegation is available when specialists have the required data tools.
Tool executionToolRegistry.execute checks the tool allowlist, resolves compute references, validates arguments and output, records evidence, and renders bounded results. Structured failures are returned to the model so it can adjust its research.
Data routingROUTES defines provider order by capability. route skips missing implementations and falls through on eligible typed errors. Batch quotes can fill eligible misses from the next provider. failureKind maps Tauric’s not_registered to unsupported, which permits a fallback where another provider serves the method. Cancellation and errors such as no_data stop the chain.
History and mathprice_history emits the series and its price basis and coverage. resolveReferences supplies that evidence payload to returns_risk. The local riskOf implementation computes measures including window returns, annualized volatility, peak-to-trough drawdown and recovery, historical VaR, and Sharpe where the inputs support them.
SynthesisThe model writes the narrative with evidence markers. citationsOf resolves numbered sources and tracks missing references. Interactive or headless output renders the result and the session wrapper commits the turn.

Price basis and timestamps matter. Yahoo’s daily series uses split- and dividend-adjusted closes, while its quote uses as-traded prices. The risk tool reports the basis from its history input when available. Both transcript risk windows end Nov 24, while the quotes are dated Nov 25. The AAPL quote shows +0.53% and its news describes an intraday decline. The pasted answer gives insufficient timing detail to reconcile those figures.

The router makes decisions by capability, method, and error kind. The SMH outcome documents coverage in this run. An instrument’s successful pricing response establishes pricing coverage for that call. Company fundamentals and analyst estimates depend on their own Tauric routes.
